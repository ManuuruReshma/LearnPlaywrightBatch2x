# LearnPlaywrightBatch2x

A simple JavaScript learning repository for Playwright batch training. This repo includes basic JavaScript examples, identifier rules, command explanations, and VS Code shortcuts.

## Repository Structure

- `chapter_01_basics/`
  - Basic JavaScript examples and commands
- `chapter_02_javascript_concepts/`
  - JavaScript concepts, identifiers, and naming conventions
- `chapter_03_identifer_literals/`
  - Identifier and literal examples

## Files

- `06_identifier_rules.js` - Valid and invalid identifier examples
- `07_identifier_Part2.js` - Naming conventions like camelCase, snake_case, PascalCase, and constants
- `08_commands.js` - JavaScript command examples and explanations
- `09_VSCode_Shortcuts_Windows.js` - Useful VS Code shortcuts for Windows

## Notes

- Use this repository to learn JavaScript syntax, naming, and workflow best practices.
- The folder `chapter_03_identifer_literals` contains the latest examples for identifiers and literals.
- Make sure to run JavaScript files with Node.js or in browser consoles.
