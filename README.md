# LearnPlaywrightBatch2x

A simple JavaScript learning repository for Playwright batch training. This repo includes basic JavaScript examples, identifier rules, command explanations, and VS Code shortcuts.

## Repository Structure

- `chapter_01_basics/`
  - Basic JavaScript examples and commands
- `chapter_02_javascript_concepts/`
  - JavaScript concepts, identifiers, and naming conventions
- `chapter_03_identifer_literals/`
  - Identifier and literal examples
- `chapter_04_Javascript_Concepts/`
  - Advanced JavaScript concepts including variables (var, let, const), functions, scope, and hoisting

## Files

### Chapter 1: Basics
- `01_basics.js` - Basic JavaScript examples
- `02_JS.js` - JavaScript fundamentals
- `03_JS_commands.js` - JavaScript command examples
- `04_HotCode.js` - Hot code reloading examples

### Chapter 2: JavaScript Concepts
- `05_JS_Basics.js` - Basic JavaScript concepts

### Chapter 3: Identifier and Literals
- `06_identifier_rules.js` - Valid and invalid identifier examples
- `07_identifier_Part2.js` - Naming conventions like camelCase, snake_case, PascalCase, and constants
- `08_commands.js` - JavaScript command examples and explanations
- `VSCode_Shortcuts_Windows.js` - Useful VS Code shortcuts for Windows

### Chapter 4: JavaScript Concepts
- `09_var_let_const.js` - Understanding var, let, and const declarations
- `10_funtions.js` - JavaScript functions
- `11_var_explained.js` - Detailed explanation of var
- `12_let_people_love.js` - Explanation of let
- `13_Const_explained.js` - Explanation of const
- `14_var_funtionscope.js` - Function scope with var
- `15_let_scope.js` - Block scope with let
- `16_hosting.js` - JavaScript hoisting concepts
- `17_hosting_funtions.js` - Hoisting behavior inside functions

## Notes

- Use this repository to learn JavaScript syntax, naming, and workflow best practices.
- The folders contain progressive examples from basic to advanced JavaScript concepts.
- Make sure to run JavaScript files with Node.js or in browser consoles.
